# Vision-JEV Model Card

## Model details

版本、日期、许可证、Qwen/processor revision、参数量、精度、视觉预算、判断头/策略头 revision。

## Intended use / out of scope

动态候选视觉判断与受限环境策略；不宣称开放世界安全自治、自由坐标发现或可信事实生成。

## Training data and procedure

链接数据卡、mixture hash、SFT/PPO run_id、硬件、时长、能耗口径和超参数。

## Evaluation

按任务/来源/语言/K/视觉预算列判断、校准、性能、proposal 与闭环指标，全部给 evidence status 和 run_id。

## Limitations and ethics

OCR/小目标、域外校准、预训练污染、候选器上限、许可、偏差、提示注入和策略概率非置信度。
