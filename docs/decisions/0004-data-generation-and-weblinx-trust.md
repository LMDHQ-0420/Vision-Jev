# ADR-0004：WebLINX 信任与零新增人工标注

> 其中“27k 本地生成”部分已由 ADR-0005 取代；WebLINX、语言和 `task_family` 决策仍有效。

- 状态：accepted
- 日期：2026-09-24
- 取代：ADR-0003 中的 WebLINX PII 门禁、固定中英文配额和增强语言策略

## 决定

1. 信任 WebLINX 上游开源发布的完整内容，不增加 OCR、PII 过滤或发布阻断。
2. 不增加逐条 `task_family` 字段；任务分布按来源用途及 Choice/Noul/Score 汇总，不调用 API 分类。
3. 不设置中英文固定配额。公开数据保留原始语言，程序场景保留原生语言，增强继承父样本语言。
4. 允许公开数据集已有的人类标签；本项目新增人工标注固定为 0。
5. 新增 30k 中，27k 本地自动生成；3k API 只做同语言语义改写，标签继承或由程序验证。

## 影响

WebLINX 可直接进入 90k 公开 manifest。完整 120k 中，90k 公开数据自动处理加 27k 本地生成均不调用生成 API，合计 117k；API 合格样本目标为 3,000 条，实际请求次数由小批 pilot 的通过率和重试率决定。任务分布是来源级近似统计，不提供逐题细粒度任务标签。
