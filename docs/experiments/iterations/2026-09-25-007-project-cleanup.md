## 目标

将仓库整理成面向公开发布的项目入口，移除已经停用的实现、历史生成资产、损坏下载和工具缓存，同时保留当前训练方案需要的原始数据、canonical 数据和 manifest。

## 代码与文档

- README 改为英文主入口，并新增完整中文版本和双向语言切换。
- README 明确项目的两个承诺：训练开放的 Vision-Jev，以及开放训练代码、数据配额、评测证据和模型权重。
- README 增加数据配方、快速开始、仓库结构、许可边界与证据驱动 TODO。
- 删除 `CONTRIBUTING.md`、`SECURITY.md`、停用的本地数据生成实现及其测试。
- 从正式依赖中移除 MiniWoB++ 和 Selenium，包标识不再使用开发版后缀。
- 活动配置和 CLI 默认路径使用稳定名称；数据 schema 版本和上游 revision 继续保留用于复现。

## 数据清理

- 删除停用的 SST 快照与下载状态。
- 删除本地生成、MiniWoB++ pilot、对应环境和浏览器缓存。
- 删除两个已标记为 invalid 的损坏下载包，共约 4.08 GB。
- 删除数据根目录中的下载缓存元数据和空锁文件。
- WebLINX 与 GUI-Odyssey 中可能仍含后续训练所需内容的原始副本未强制删除，以避免破坏 117k 构建。

## 保留原则

15 个活动来源的原始数据、解压内容、canonical JSONL、有效公开数据 pilot、90k 核心 manifest 和所有可复现账本均保留。上游压缩包即使已有解压副本，也按“原始数据必须保留”的要求保留。
