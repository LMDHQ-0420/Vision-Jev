因此 117k 可完全自动处理且无需生成 API；3k 是最终合格的 API 辅助样本，实际请求次数须按 pilot 的通过率和重试率另记。公开数据集已有的人类标签允许使用。

公开来源题型合计为 94k Choice、17k Noul、6k Score。最终 3k 改写从已有 Choice/Noul 父样本产生 2k/1k，不翻译，继承父样本语言和标签语义。KonIQ 的 Score 表示由上游人类 MOS 在 train 中确定的五等分位相对质量等级，不解释为“动作成功概率”；原始评分分布保留用于审计。

不设置中英文固定配额：公开数据保留原始语言，API 改写继承父样本语言。Choice 的目标 K 分布仍为：2–4 占 55%，5–8 占 30%，9–16 占 10%，17–32 占 5%；只有在来源原生候选或自动构造负例足够时才纳入对应档位。

任务分布不增加逐条 `task_family`，也不调用 API 分类。来源级近似分布为：GUI/动作 36k、区域/候选定位 24k、关系/科学/组合推理 29k、普通 VQA 8k、OCR 6k、图表 6k、纯文本逻辑 2k、视觉质量 Score 6k、API 改写 3k。它是有意面向项目目标的非均匀分布，不冒充逐题语义统计。

## 运行规则

- `pilot-12k` 按主配方 10% 分层抽样，只在 50–200 样本过拟合通过后执行。
- 改变任一来源、过滤器、候选器或比例，必须产生新 mixture ID、manifest hash 和迭代记录。
- 头部消融固定数据 hash、顺序、视觉预算、LoRA、优化器和训练步数。
- 来源不足先写缺口报告；只能显式修订配额或降低总量，不能用本地生成或教师生成静默补缺。
- 停用的本地生成与 MiniWoB 资产已从活动数据目录删除，不进入 canonical pool、manifest 或训练。
